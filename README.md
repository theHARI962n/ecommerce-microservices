# Ecommerce Microservice

Building a distributed e-commerce platform using Microservices Architecture with Spring Boot, Spring Cloud, PostgreSQL, and REST APIs.
The project focuses on service decomposition, inter-service communication, database-per-service design, API gateway routing, and scalable backend system development using Java and Spring Boot.

## Services
- User Service
- Product Service
- Cart Service
- Order Service
- Payment Service
- API Gateway
